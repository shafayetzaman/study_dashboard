# 📚 Personal Study Plan

A personal study planning and tracking website built to organize my preparation, track daily study progress, and keep everything I need in one place.

The goal of this project is simple: **study consistently, track progress, and stay focused until the admission exams.**

## ✨ Features

* ⏱️ **Study Timer** — Track study time with normal and Pomodoro modes.
* 📊 **Daily Study Hours** — Automatically record completed study time and manually edit it when necessary.
* 🎯 **Study Goal Progress** — Track progress toward a customizable overall study-hour goal.
* 📈 **Progress Dashboard** — Get a quick overview of study progress and remaining goals.
* 📚 **Chapter Tracker** — Keep track of completed and pending chapters.
* 🌙 **Dark Mode UI** — Designed entirely around a modern dark interface.
* 💾 **Personal Data** — Designed for personal use with data stored locally where applicable.

## 🛠️ Tech Stack

* **React**
* **Vite**
* **JavaScript**
* **Tailwind CSS**
* **React Router**
* **Local Storage**

## 🎯 Purpose

This isn't intended to be a general-purpose productivity application.

It's a personal tool I built specifically for my **HSC and university admission preparation** so I can replace scattered notes, timers, planners, and progress tracking with a single dashboard.

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
```

Navigate to the project:

```bash
cd your-repository-name
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.
